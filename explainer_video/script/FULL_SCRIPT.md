# Hermes Agent Explainer — Full Narration Script (en-IN)

## B1 — What is Hermes Agent? (slides S01, S02, S03)

Namaste, and welcome to the complete Hermes Agent explainer. Hermes Agent, built by Nous Research, is the self-improving A I agent with a built-in learning loop. It creates skills from experience, improves them while you work, reminds itself to save what matters, searches its own past conversations, and builds a deeper model of you in every session. Here is the big picture. You can talk to it from the terminal, or from Telegram, Discord, Slack, WhatsApp, and Signal, while it actually runs on a cloud machine. It works with almost any model you choose, from Nous Portal to OpenRouter and OpenAI, and you can switch models with one command. In this video, we will unpack the architecture, the learning loop, the platforms, the automations, and the two-minute quick start, step by step, with tables and diagrams. Let us begin. 

## B2 — Architecture: three layers (slides S04, S05, S06)

Let us open the hood. Hermes has three layers. Layer one is the interface layer. You either type in a full terminal interface, with multi-line editing, slash commands, history, and streaming tool output, or you message it from chat apps through a single gateway process. Layer two is the agent runtime. This is the brain. It runs the conversation loop, calls more than forty tools, delegates work to isolated sub-agents, compresses old context so long sessions never break, and tracks usage and cost. Layer three is the state layer. Every session, message, and memory is stored in a local database with full-text search, so the agent can recall anything across sessions. Follow one message. You send a text on Telegram. The gateway routes it to your session, the runtime thinks, calls tools, and replies, and the state layer saves everything for next time. One brain, many doors, total memory. 

## B3 — The closed learning loop (slides S07, S08)

This is the heart of Hermes, the closed learning loop, and it has five moving parts. Part one, agent-curated memory with periodic nudges. The agent itself decides what is worth remembering, and the system nudges it to persist knowledge before it is lost. Part two, autonomous skill creation. After a complex task, Hermes writes a reusable skill from what it just learned, so it never solves the same problem twice. Part three, skills that self-improve during use. Every time a skill runs, the agent refines it. Part four, session search with summarisation. Full-text search finds old conversations, and the model summarises them for cross-session recall. Part five, a deepening model of you, powered by Honcho, an open-source user-modelling system, plus compatibility with the open agentskills dot io standard. Memory writes, skills learn, recall compounds. That is why Hermes gets smarter the longer you use it. 

## B4 — Lives anywhere, runs anywhere (slides S09, S10)

Hermes lives where you do, and runs where you want. First, where you talk. One gateway process serves Telegram, Discord, Slack, WhatsApp, Signal, and the command line together. It transcribes your voice memos, and your conversation continues seamlessly even if you switch apps. Now, where it runs. Hermes has seven terminal backends. Local for your own machine, Docker and SSH for servers, Singularity for clusters, and Modal, Daytona, and Vercel Sandbox for the cloud. The serverless options are special. Your agent's environment hibernates when idle and wakes on demand, so it costs almost nothing between sessions. That means one setup choice covers everything, from a five-dollar V P S to a full G P U cluster. Chat from your phone, compute in the cloud. 

## B5 — Delegation, automation, research (slides S11, S12)

Now the power features. Delegation, automation, and research. Delegation first. Hermes can spawn isolated sub-agents for parallel workstreams, so three tasks finish in the time of one. It can also write Python scripts that call its own tools through R P C, collapsing long multi-step pipelines into a single step that costs almost zero context. Automation next. A built-in cron scheduler takes plain-English schedules, like a daily report, a nightly backup, or a weekly audit, and delivers the result to any platform, fully unattended. Finally, research. Hermes supports batch trajectory generation and trajectory compression, producing training data for the next generation of tool-calling models. Parallel workers, scheduled habits, and a data flywheel for researchers. Let us get you installed. 

## B6 — Install + quickstart + closing (slides S13, S14, S15)

On Linux, macOS, W S L two, or Termux, you run one install command from the Hermes docs site, then reload your shell and type hermes to start chatting. On Windows, there is a native PowerShell installer that bundles everything, including Python, Node, and a portable Git. Day to day, you need only a few commands. Hermes model to switch providers, hermes gateway to start messaging, hermes setup for the full wizard, hermes update to upgrade, and hermes doctor to diagnose problems. Want to skip collecting five A P I keys? Run hermes setup with the portal flag. One Nous Portal subscription gives you three hundred plus models, plus web search, image generation, speech, and a cloud browser through the Tool Gateway. Full docs are on the Hermes site, and the community lives on Discord. Thank you for watching, and happy building with Hermes Agent.
